Personvernerklæring

Hvordan lokale data, eksport og dette nettstedet håndteres.

Ansvarlig og kontakt

PlumpPad utvikles og tilbys av Jonas Hedberg. Spørsmål om personvern kan stilles via GitHub Issues i PlumpPad-repositoriet. Ingen direkte e-postadresse publiseres. GitHub Issues er offentlige, så ikke legg ut konfidensielle opplysninger.

Data lagret på enheten

Appen kan lagre navn, rekkefølge, giver, meldinger, stikk, poeng, spillstatus, datoer, resultater og egne regelsett. Pågående spill lagres automatisk; historikk for avsluttede spill er valgfri. Opplysningene brukes til poengberegning og gjenopptakelse. Ingen konto kreves.

Innsamling og tredjeparter

Den gjennomgåtte versjonen sender ikke spilldata til utvikleren eller egne servere. Den har ingen annonser, tredjepartsanalyse eller sporing og deler ikke automatisk data med annonsører. Dette gjelder den undersøkte versjonen.

Utskrift, deling og sikkerhetskopier

PDF- og CSV-filer lages først når du velger det via iOS-funksjoner. Mottakeren kan behandle filene etter egne vilkår. Lokale data kan inngå i iOS-/iCloud-sikkerhetskopier avhengig av innstillingene.

Lagring og sletting

Pågående spill lagres til de avsluttes eller slettes; avsluttede spill beholdes når historikk er på. Lagrede spillere og regler finnes lokalt. Slett spill og historikk i appen eller fjern appen; sikkerhetskopier og eksporterte kopier håndteres separat.

Nettsted og GitHub

Dette nettstedet leveres via GitHub Pages og bruker ingen egne analysekapsler, annonser eller sporingsskript. GitHub kan behandle tekniske tilkoblingsdata etter sin personvernpolicy. Offentlige issues behandles også av GitHub.

Spørsmål og rettigheter

Utvikleren mottar ikke spilldata og kan normalt verken lese eller slette dem eksternt. Administrer dem på enheten. Bruk GitHub Issues for generelle spørsmål uten å legge ut personopplysninger.
