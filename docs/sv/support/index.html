Support för PlumpPad

Här finns hjälp för PlumpPad på iPhone och iPad. Support, felrapporter och önskemål hanteras via GitHub-repositoryt PlumpPad.

Vanliga frågor

Kan jag fortsätta ett spel senare?

Ja. Ett pågående spel sparas lokalt efter ändringar och visas på startsidan när appen öppnas igen.

Hur tar jag bort ett pågående spel?

På startsidan kan du välja papperskorgen vid det aktiva spelet och bekräfta att spelet ska överges.

Hur hanterar jag sparade spelare?

Öppna Inställningar → Sparade spelare. Där kan du lägga till eller radera namn. Vid nytt spel kan sparade spelare väljas från spelarplatsens meny eller så kan namn skrivas in manuellt.

Hur fungerar resultathistoriken?

I Inställningar kan du välja om färdigspelade resultat ska sparas. När historik är aktiverad kan sparade resultat visas och raderas från Historik. Pågående spel påverkas inte av den inställningen.

Hur skriver jag ut resultat?

Öppna poängöversikten eller slutresultatet och välj utskrift. PlumpPad kan skapa resultatrapport för A4 eller US Letter och använder iOS systemdialog för utskrift.

Vilka språk stöds?

Svenska och engelska. Appen följer det språk som iOS använder för appen.

Behöver PlumpPad internet?

Nej för appens kärnfunktioner. Den granskade versionen har ingen egen nätverkskommunikation. GitHub-supporten och denna webbplats kräver förstås internetåtkomst.

Så rapporterar du ett problem

Öppna ett GitHub-ärende och ange gärna:

  • vilken iPhone- eller iPad-modell du använder,
  • iOS/iPadOS-version,
  • PlumpPad-version,
  • vad du gjorde före problemet,
  • vad du förväntade dig och vad som hände i stället.

Undvik att lägga in privata uppgifter i ett publikt GitHub-ärende.
