Support & hjälp

Hjälp med installation, spelgång, resultat och vanliga frågor.

Rapportera ett problem eller föreslå en förbättring

Använd GitHub Issues i repositoryt PlumpPad. Där kan du rapportera fel, ställa frågor eller lämna förbättringsförslag. GitHub-inloggning krävs normalt för att skapa ett ärende.

Vanliga frågor

Mer detaljerad hjälp finns i appens inbyggda spelregler.

Hur startar jag ett parti?

Öppna Nytt spel, välj 2–8 spelare, ange namn eller välj sparade spelare, kontrollera sittordningen och välj första givare.

Hur fortsätter jag ett pausat spel?

Pågående spel sparas automatiskt på enheten. Öppna partiet från startsidan för att fortsätta.

Varför saknas ett bud för givaren?

Givaren budar sist och får inte lägga ett bud som gör summan av alla bud lika med antalet stick i omgången.

Hur registrerar jag tagna stick?

Efter budgivningen väljer du antalet tagna stick för varje spelare i menyn. Summan måste motsvara antalet stick i omgången.

Hur fungerar poängberäkningen?

Exakt antal tagna stick ger 10 plus antalet stick. Ett missat bud ger 0 poäng och en plump.

Kan jag återanvända spelarnamn?

Ja. Lägg till sparade spelare under Inställningar och välj dem i formuläret för ett nytt spel.

Hur tar jag bort sparade resultat?

Öppna Inställningar och välj Rensa sparad historik. Historikinställningen påverkar inte pågående spel.

Kan jag skriva ut eller exportera?

Ja. Poängöversikt och slutresultat erbjuder PDF-utskrift på A4/Letter och CSV-delning via iOS.

Hur byter jag språk?

PlumpPad finns på svenska och engelska. Språket följer iOS språkval eller språkval för appen i enhetens Inställningar.

Behöver jag internet?

Nej, själva poängräkningen fungerar offline. GitHub-support och den här webbplatsen kräver internet.
