Om PlumpPad

PlumpPad är ett hjälpmedel för poänghantering i kortspelet Plump. Appen räknar och presenterar resultat utifrån den regelprofil som beskrivs i appen. Användaren ansvarar själv för hur ett faktiskt kortparti genomförs och för eventuella husregler.
