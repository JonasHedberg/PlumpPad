Om appen

PlumpPad är ett hjälpmedel för att föra poängprotokoll i kortspelet Plump. Appen delar inte ut kort eller avgör hur fysiska stick spelas. Regler kan skilja sig mellan spelgrupper; appens poängmodell beskrivs på regelsidan.

PlumpPad erbjuder flera förinställda regelprofiler och egna husregler. Profilerna är tekniska poänginställningar och ska inte tolkas som officiella eller allmängiltiga regler för ett helt land.

Licensvillkor

Om appen hämtas via App Store och inget särskilt slutanvändaravtal anges för appen gäller Apples standardlicensavtal för appar (Standard EULA). Apples villkor reglerar då rätten att använda appen.

Riktighet och support

Appens resultat beror på vilka bud och stick som användaren registrerar. Kontrollera gärna protokollet vid behov. Felrapporter och frågor kan skickas via GitHub Issues. Lagstadgade konsumenträttigheter påverkas inte av denna information.

PlumpPad

Det digitala poängblocket för Plump. Byggd för iPhone och iPad, med fokus på enkelhet och integritet.
