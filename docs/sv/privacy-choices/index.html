Avslutade spel och historik

Öppna Inställningar → Spara resultathistorik för att välja om framtida avslutade partier ska behållas. Välj Rensa sparad historik för att ta bort sparade avslutade resultat. Att stänga av historiken raderar inte automatiskt gamla historikposter.

Pågående spel

Pågående spel sparas så att ni kan fortsätta senare. Ta bort ett spel från startsidans spellista när du inte längre vill behålla det.

Sparade spelarnamn

Under Inställningar finns listan över sparade spelare. Ta bort namn där när du inte vill återanvända dem. Äldre protokoll kan fortfarande innehålla namnen tills du raderar respektive spel.

Rapporter och utskrifter

PDF-utskrifter och CSV-filer skapas på din enhet när du väljer det. Har du sparat eller delat en fil måste eventuella kopior hanteras i den app, tjänst eller enhet där de finns.

Radera all lokal appdata

Om du avinstallerar PlumpPad tas appens lokala data normalt bort från enheten. Kopior i iOS-säkerhetskopior, exporterade filer och andra appar omfattas inte nödvändigtvis av detta.

Ingen inloggning eller serverlagring

PlumpPad har inga användarkonton eller utvecklarserver där speldata lagras. Därför finns ingen serverbaserad konto- eller speldatahantering att begära radering av. Frågor kan lämnas via GitHub Issues (tänk på att ärenden är offentliga).
