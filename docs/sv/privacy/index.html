Ansvarig

PlumpPad utvecklas och tillhandahålls av Jonas Hedberg. För frågor om appen eller integritet används PlumpPad på GitHub Issues. Det finns ingen e-postbaserad supportkanal på denna webbplats.

Information som lagras i appen

Appen kan spara namn som du själv anger för spelare, sittordning, givare, bud, tagna stick, poäng, plumpar, spelstatus, datum och resultat. Pågående partier sparas automatiskt. Avslutade partier kan sparas i historiken om du väljer det. Sparade spelarnamn och inställningar finns också lokalt.

Uppgifterna används för att beräkna poäng, visa pågående partier, återuppta spel, presentera resultat och skapa rapporter. Inget användarkonto behövs.

Anpassade och sparade husregler (namn och inställningar för poäng, givschema och spelare) lagras också lokalt på enheten. En vald regeluppsättning kan ingå i ett sparat partis data.

Datainsamling och tredje parter

Den granskade appversionen skickar inte speluppgifter till Jonas Hedberg eller någon egen server och innehåller ingen reklam, tredjepartsanalys eller spårningsfunktion. Inga uppgifter från appen säljs eller delas automatiskt med annonsörer eller analytiktjänster.

Denna beskrivning gäller den granskade versionen. Om framtida versioner ändrar datahanteringen uppdateras policyn.

Utskrift, export och säkerhetskopiering

När du själv väljer att skriva ut ett PDF-protokoll eller dela/exportera en CSV-fil använder appen Apples systemfunktioner. Mottagaren, skrivaren eller tjänsten som du väljer kan då behandla filens innehåll enligt sina egna villkor. PlumpPad skickar inte rapporter automatiskt.

Lokala appdata kan omfattas av enhetens ordinarie säkerhetskopiering, beroende på iOS- och iCloud-inställningar. Exporterade filer eller kopior i andra appar hanteras där du har sparat eller delat dem.

Lagringstid och radering

Pågående spel finns kvar tills de avslutas eller raderas. Avslutade spel behålls i historiken om historik var aktiverad när de slutfördes, tills de tas bort. Sparade spelare finns kvar tills de raderas. Appens egna inställningar finns kvar tills de ändras eller appens data tas bort.

Du kan radera sparade spelare och historik i Inställningar, ta bort spel från appens spelöversikt och ta bort appen för att radera dess lokala lagring från enheten. Säkerhetskopior och exporterade kopior kan behöva hanteras separat. Se Dataval och radering.

Den här webbplatsen och GitHub

Webbplatsen publiceras via GitHub Pages. Den använder inga egna cookies för statistik, inga tredjepartsannonser och inga analys- eller spårningsskript. GitHub kan behandla tekniska anslutningsuppgifter när webbplatsen levereras enligt GitHubs integritetspolicy.

Om du öppnar eller skapar ett ärende via GitHub Issues behandlas uppgifter av GitHub. Ett ärende och dess kommentarer kan vara offentliga. Publicera därför inte känslig information eller privata spelardetaljer i ett ärende.

Frågor och rättigheter

Eftersom appen inte tar emot spelinformationen kan utvecklaren normalt inte läsa, exportera eller radera den på distans. Hantera uppgifterna på din enhet. Om du har frågor om personuppgifter eller vill kontakta ansvarig använder du ett ärende i PlumpPad-repositoryt utan att ange känsliga uppgifter offentligt.
