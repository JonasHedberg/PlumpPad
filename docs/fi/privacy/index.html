Rekisterinpitäjä ja yhteydenotto

PlumpPadin kehittää ja tarjoaa Jonas Hedberg. Tietosuojaa koskevat kysymykset voi esittää PlumpPadin GitHub Issues -palvelussa. Sivustolla ei julkaista suoraa sähköpostiosoitetta. Ilmoitukset ovat julkisia, joten älä jaa luottamuksellisia tietoja.

Laitteelle tallennettavat tiedot

Sovellus voi tallentaa nimet, istumajärjestyksen, jakajan, tarjoukset, tikit, pisteet, pelin tilan, päivämäärät, tulokset ja omat sääntöjoukot. Käynnissä olevat pelit tallentuvat automaattisesti; päättyneiden pelien historia on valinnainen. Tietoja käytetään pisteytykseen ja jatkamiseen. Käyttäjätiliä ei tarvita.

Tietojen kerääminen ja kolmannet osapuolet

Tarkistettu sovellusversio ei lähetä pelitietoja kehittäjälle tai hänen palvelimilleen. Siinä ei ole mainoksia, kolmannen osapuolen analytiikkaa tai seurantaa eikä automaattista tietojen luovutusta mainostajille. Kuvaus koskee tarkistettua versiota.

Tulostus, jakaminen ja varmuuskopiot

PDF- ja CSV-tiedostoja luodaan vain käyttäjän pyynnöstä iOS-toiminnoilla. Valittu vastaanottaja käsittelee tietoja omien ehtojensa mukaisesti. Paikallisia tietoja voi sisältyä iOS-/iCloud-varmuuskopioihin laitteen asetuksista riippuen.

Säilytys ja poistaminen

Keskeneräiset pelit säilyvät, kunnes ne päättyvät tai ne poistetaan. Päättyneet pelit säilyvät, jos historia on käytössä. Pelaajat ja säännöt pysyvät paikallisina. Poista tiedot sovelluksesta tai sovellus; varmuuskopiot ja viedyt tiedostot on käsiteltävä erikseen.

Verkkosivusto ja GitHub

Sivusto sijaitsee GitHub Pagesissa eikä käytä omia analytiikkaevästeitä, mainoksia tai seurantaskriptejä. GitHub voi käsitellä teknisiä yhteystietoja tietosuojakäytäntönsä mukaisesti. Julkiset ilmoitukset ovat myös GitHubin käsiteltäviä.

Kysymykset ja oikeudet

Kehittäjä ei saa pelitietoja eikä yleensä voi tarkastella tai poistaa niitä etänä. Hallinnoi tietoja laitteella. Esitä yleiset kysymykset GitHub Issuesissa julkaisematta henkilötietoja.
