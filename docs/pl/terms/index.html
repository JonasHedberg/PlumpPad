Przeznaczenie aplikacji

PlumpPad zapisuje wyniki Plump i podobnych gier lewowych. Nie rozdaje kart i nie rozstrzyga fizycznych lew. Profile są technicznymi ustawieniami, a nie obowiązującymi zasadami krajowymi.

Licencja
