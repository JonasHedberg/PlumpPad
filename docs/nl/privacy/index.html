Verantwoordelijke en contact

PlumpPad wordt ontwikkeld en aangeboden door Jonas Hedberg. Voor privacyvragen kun je GitHub Issues in de repository PlumpPad gebruiken. Er staat geen rechtstreeks e-mailadres op deze website. Issues zijn openbaar; plaats geen vertrouwelijke informatie.

Gegevens op je apparaat

De app kan namen, zitvolgorde, deler, biedingen, slagen, scores, spelstatus, data, uitslagen en eigen regelsets opslaan. Lopende spellen worden automatisch bewaard; geschiedenis van afgeronde spellen is optioneel. Deze gegevens dienen voor scoreberekening en hervatten. Een account is niet nodig.

Verzameling en derden

De beoordeelde versie verstuurt geen spelgegevens naar de ontwikkelaar of diens servers. Er zijn geen advertenties, externe analytics of tracking en geen automatische overdracht naar adverteerders. Dit geldt voor de beoordeelde versie.

Printen, export en back-ups

PDF's en CSV-bestanden worden alleen op jouw verzoek gemaakt met iOS-functies. De gekozen ontvanger kan gegevens verwerken volgens zijn eigen voorwaarden. Lokale gegevens kunnen afhankelijk van je instellingen in iOS-/iCloud-back-ups staan.

Bewaartermijnen en wissen

Lopende spellen blijven totdat je ze afrondt of verwijdert. Voltooide spellen blijven bewaard als geschiedenis aanstond. Spelers en regels worden lokaal bewaard. Verwijder ze in de app of verwijder de app; back-ups en gedeelde kopieën moet je apart beheren.

Website en GitHub

Deze site wordt via GitHub Pages aangeboden en gebruikt geen eigen analyticscookies, advertenties of trackingscripts. GitHub kan technische verbindingsgegevens verwerken volgens zijn privacybeleid. Openbare issues worden ook door GitHub verwerkt.

Vragen en rechten

De ontwikkelaar ontvangt je spelgegevens niet en kan deze daarom normaal niet op afstand inzien of verwijderen. Beheer gegevens op je apparaat. Stel algemene vragen via GitHub Issues zonder persoonsgegevens te publiceren.
