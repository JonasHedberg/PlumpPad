Privatlivspolitik

Hvordan lokale data, eksport og denne hjemmeside håndteres.

Sidst opdateret: 28.10.2026

Ansvarlig og kontakt

PlumpPad udvikles og leveres af Jonas Hedberg. Spørgsmål om privatliv kan stilles via GitHub Issues i PlumpPad-repositoriet. Der offentliggøres ingen direkte e-mailadresse. GitHub Issues er offentlige, så del ikke fortrolige oplysninger.

Oplysninger gemt på enheden

Appen kan gemme spillernavne, siddeorden, kortgiver, meldinger, stik, point, spilstatus, datoer, resultater og husregler. Igangværende spil gemmes automatisk; historik over afsluttede spil er valgfri. Data bruges til pointberegning og genoptagelse. Ingen konto er nødvendig.

Indsamling og tredjeparter

Den undersøgte version sender ikke spildata til udvikleren eller hans servere. Den har ingen annoncer, tredjepartsanalyse eller sporing og deler ikke automatisk data med annoncører. Beskrivelsen gælder den gennemgåede version.

Udskrift, deling og backup

PDF- og CSV-filer oprettes kun efter dit valg gennem iOS-funktioner. Valgte modtagere kan behandle filerne efter egne vilkår. Lokale data kan være med i iOS-/iCloud-sikkerhedskopier afhængigt af dine indstillinger.

Opbevaring og sletning

Igangværende spil gemmes indtil afslutning eller sletning; afsluttede spil gemmes, når historik er slået til. Spillere og regelsæt gemmes lokalt. Slet spil og historik i appen eller fjern appen; backup og eksporterede kopier skal håndteres særskilt.

Hjemmesiden og GitHub

Hjemmesiden ligger på GitHub Pages og bruger ingen egne analysecookies, annoncer eller sporingsscripts. GitHub kan behandle tekniske forbindelsesoplysninger efter sin politik. Offentlige issues behandles også af GitHub.

Spørgsmål og rettigheder

Udvikleren modtager ikke spildata og kan derfor normalt ikke læse eller slette dem på afstand. Håndter data på enheden. Brug GitHub Issues til generelle spørgsmål uden at offentliggøre personoplysninger.
