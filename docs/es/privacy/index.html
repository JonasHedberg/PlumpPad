Responsable y contacto

PlumpPad es desarrollado y ofrecido por Jonas Hedberg. Las consultas se atienden mediante GitHub Issues del repositorio PlumpPad, sin publicar un correo electrónico directo. Las incidencias son públicas; no incluyas datos confidenciales.

Datos guardados en el dispositivo

La aplicación puede almacenar nombres, orden de asientos, repartidor, apuestas, bazas, puntuaciones, estado, fechas, resultados y conjuntos de reglas propios. Las partidas activas se guardan automáticamente y el historial de las terminadas es opcional. Estos datos permiten puntuar y reanudar partidas. No se necesita cuenta.

Recopilación y terceros

La versión examinada no envía datos de juego al desarrollador ni a servidores propios. No incluye anuncios, analítica de terceros ni seguimiento, y no comparte automáticamente datos con anunciantes. Esto describe la versión revisada.

Impresión, exportación y copias

Los PDF y CSV se generan cuando lo solicitas con funciones de iOS. El destinatario elegido puede tratar los archivos según sus propias políticas. Las copias de seguridad iOS/iCloud pueden incluir información local según los ajustes del dispositivo.

Conservación y eliminación

Las partidas activas permanecen hasta completarse o borrarse; las terminadas se conservan si el historial está activado. Los jugadores y reglas guardados siguen en el dispositivo. Borra partidas e historial en la app o desinstálala; gestiona por separado copias y exportaciones.

Sitio web y GitHub

Este sitio utiliza GitHub Pages. No incorpora cookies de analítica propias, anuncios ni scripts de rastreo. GitHub puede procesar datos técnicos de conexión según su política. Los comentarios e incidencias publicados en GitHub también se procesan allí.

Derechos y consultas

Como el desarrollador no recibe los datos de las partidas, normalmente no puede verlos ni borrarlos a distancia. Contrólalos en el dispositivo. Para preguntas generales utiliza GitHub Issues sin publicar datos personales.
