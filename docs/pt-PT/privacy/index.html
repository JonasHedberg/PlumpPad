Política de privacidade

Responsável e contacto

O PlumpPad é desenvolvido e disponibilizado por Jonas Hedberg. Para questões de privacidade, use o GitHub Issues do repositório PlumpPad. Não é publicado um endereço de correio eletrónico direto. As issues são públicas; não partilhe dados confidenciais.

Dados guardados no dispositivo

A aplicação pode guardar nomes, lugares, distribuidor, apostas, vazas, pontos, estado dos jogos, datas, resultados e conjuntos de regras personalizados. Os jogos em curso são guardados automaticamente; o histórico dos concluídos é opcional. Os dados servem para calcular pontos e retomar jogos. Não é necessária conta.

Recolha de dados e terceiros

A versão analisada não envia dados de jogos ao programador nem a servidores seus. Não tem anúncios, análise de terceiros ou rastreio, nem partilha automática de dados com anunciantes. Esta descrição refere-se à versão analisada.

Impressão, partilha e cópias de segurança

Os PDF e CSV só são gerados a seu pedido através das funções do iOS. O destinatário escolhido poderá tratar os dados segundo as suas condições. Os dados locais podem constar de cópias de segurança iOS/iCloud, consoante as definições.

Conservação e eliminação

Os jogos em curso mantêm-se até serem concluídos ou apagados. Os concluídos são guardados se o histórico estiver ativo. Jogadores e regras permanecem localmente. Apague jogos e histórico na aplicação ou desinstale-a; cópias de segurança e exportações devem ser geridas separadamente.

Sítio e GitHub

Este sítio é alojado no GitHub Pages e não usa cookies analíticos próprios, anúncios ou scripts de rastreio. O GitHub pode tratar dados técnicos de ligação de acordo com a sua política. As issues públicas são também tratadas pelo GitHub.

Questões e direitos

Como o programador não recebe os dados dos jogos, normalmente não os pode consultar nem apagar à distância. Faça a gestão no dispositivo. Use GitHub Issues para questões gerais sem publicar dados pessoais.
