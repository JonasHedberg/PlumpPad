# PlumpPad GitHub Pages (`docs/`)

This folder is ready to be placed as `/docs` in the **PlumpPad** GitHub repository.

## Publish on GitHub Pages

1. Commit the entire `docs` folder to the repository's default branch (normally `main`).
2. On GitHub, open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select the branch containing this folder and choose **`/docs`** as the publishing source.
5. After deployment, the site will normally be available at:
   `https://<github-username>.github.io/PlumpPad/`

The website does not hard-code a GitHub username. On a standard `*.github.io` Pages host, `assets/site.js` derives the repository owner from the hostname and sends Support buttons to that owner's **PlumpPad** repository / GitHub Issues.

## Languages

- Swedish: `/sv/`
- English: `/en/`

## App Store Connect URLs

Use the localized URLs listed in `APP_STORE_CONNECT.md` after replacing `<github-username>` with the account or organization that owns the repository.

## No direct email address

Per project requirements, this site publishes no direct email address. Support is routed to GitHub Issues. See the compliance note in `APP_STORE_CONNECT.md` regarding Apple's current wording for Support URL contact information.
