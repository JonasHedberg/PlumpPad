Titolare e contatti

PlumpPad è sviluppata e fornita da Jonas Hedberg. Per domande sulla privacy usa GitHub Issues nel repository PlumpPad; non è pubblicato alcun indirizzo e-mail diretto. Le segnalazioni sono pubbliche: non inserire informazioni riservate.

Informazioni salvate localmente

L'app può memorizzare nomi, posti, mazziere, dichiarazioni, prese, punti, stato, date, risultati e regole personalizzate. Le partite attive si salvano automaticamente; la cronologia delle partite concluse è facoltativa. I dati servono al punteggio e alla ripresa. Non occorre un account.

Raccolta dati e terze parti

La versione esaminata non invia dati delle partite allo sviluppatore o a server gestiti da lui. Non include pubblicità, analisi di terze parti o tracciamento. Non trasferisce automaticamente dati agli inserzionisti. Le dichiarazioni si riferiscono alla versione esaminata.

Stampa, condivisione e backup

PDF e CSV vengono creati su richiesta tramite le funzioni di iOS. Il destinatario scelto può trattare i dati secondo le proprie condizioni. I backup iOS/iCloud potrebbero includere i dati locali in base alle impostazioni del dispositivo.

Conservazione e cancellazione

Le partite attive restano finché non vengono concluse o eliminate; quelle concluse se la cronologia è attiva. Giocatori e regole salvati restano locali. Elimina partite e cronologia nell'app o disinstallala; backup ed esportazioni devono essere gestiti separatamente.

Sito web e GitHub

Il sito usa GitHub Pages e non inserisce cookie analitici propri, annunci o script di tracciamento. GitHub può trattare i dati tecnici di connessione in base alla propria informativa. Le issue pubbliche sono gestite da GitHub.

Domande e diritti

Poiché lo sviluppatore non riceve i dati di gioco, normalmente non può consultarli o cancellarli a distanza. Gestiscili sul dispositivo. Per questioni generali usa GitHub Issues senza pubblicare dati personali.
