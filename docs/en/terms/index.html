About the app

PlumpPad helps keep score for the trick-taking card game Plump. It does not deal cards or determine the outcome of physical tricks. Rules can differ between groups; the app’s scoring profile is described on the rules page.

Accuracy and support

The app’s score calculations depend on the bids and tricks entered by users. Check entries if needed. Bugs and questions can be reported through GitHub Issues. This information does not limit applicable statutory consumer rights.
