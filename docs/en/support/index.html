PlumpPad Support

Help for PlumpPad on iPhone and iPad. Support requests, bug reports and feature requests are handled through the PlumpPad GitHub repository.

Open a support issue on GitHubView existing issues

Frequently asked questions

Can I continue a game later?

Yes. An active game is stored locally after changes and appears on the home screen when you reopen the app.

How do I remove an active game?

On the home screen, select the trash button next to the active game and confirm that you want to abandon it.

How do saved players work?

Open Settings → Saved Players. You can add or remove names there. When starting a new game, choose saved players from each seat’s menu or enter names manually.

How does result history work?

Settings lets you decide whether completed results are retained. When history is enabled, saved results can be viewed and deleted from History. Active games are not affected by that setting.

How do I print results?

Open the scoreboard or final results and choose print. PlumpPad can generate a results report for A4 or US Letter and uses the iOS system printing interface.

Which languages are supported?

Swedish and English. The app follows the language selected for it in iOS.

Does PlumpPad need internet access?

Not for core app functionality. The reviewed version has no developer-operated network communication. GitHub support and this website naturally require internet access.

How to report an issue

Open a GitHub issue and, if possible, include:

  • your iPhone or iPad model,
  • iOS/iPadOS version,
  • PlumpPad version,
  • what you did before the issue occurred,
  • what you expected and what happened instead.

Avoid posting private information in a public GitHub issue.
