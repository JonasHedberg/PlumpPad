Frequently asked questions

Frequently asked questions about rule presets, scoring and settings in the latest version.

How do I choose the rules?

Open New Game and select Country or variant under Ruleset. Open House rules to customize the preset.

Can I save custom house rules?

Yes. Choose Save current house rules in New Game and give the set a name. You can select it again under Saved house rules.

How many players are supported?

The Swedish default supports 2–8 players. Other presets have their own limits, shown when you configure a new game.

Do all variants score the same way?

No. Exact-bid bonuses, penalties and trick values differ. Consult the rules section and selected rule set.

Why can’t the dealer choose a bid?

When the final-bid restriction is enabled, the last bidder cannot make total bids equal the number of available tricks. Some profiles disable this restriction.

How do I enter tricks taken?

Use plus/minus or the dropdown beside each player. The sum of tricks must match the number available in the round.

Can I correct the previous bid?

During bidding, you can edit the immediately preceding bidder’s entry before bidding progresses further.

How do I pause a game?

Leave the game using Pause. It is saved on-device and can be resumed from the home screen.

Can I keep the display awake?

Yes. Enable Keep screen awake in Settings. You may also enable dimming after about 60 seconds of inactivity during a game.

Where are players and results saved?

Manage saved players in the Players tab. Settings controls whether finished games are retained and lets you clear stored history. Active games are unaffected.

Can I print or export?

Yes. The final-results screen provides CSV export for Numbers/Excel and PDF printing. Choose A4 or US Letter in Settings.

Which languages are supported?

PlumpPad supports 12 interface languages: Swedish, English, German, French, Spanish, Italian, Polish, Dutch, Danish, Norwegian Bokmål, Finnish and European Portuguese. Select the app language in iOS Settings.

Do I need internet access?

Not for scoring and local game data. This website and GitHub support require an internet connection.
