Objet de l’application

PlumpPad tient les scores de Plump et de jeux de plis similaires. Il ne distribue pas de cartes physiques et ne juge pas les plis. Les profils proposés sont des paramètres de calcul, pas des règles officielles imposées à un pays.

Licence

Si l’app est obtenue sur l’App Store, le contrat de licence standard d’Apple (Standard EULA) s’applique sauf autre licence expressément fournie. Les droits légaux des consommateurs restent applicables.

Droit d’auteur

© 2026 Jonas Hedberg. Le nom, le design, le code et les éléments graphiques sont protégés par la législation applicable. Les marques de tiers appartiennent à leurs détenteurs.

Exactitude et assistance

Les calculs reposent sur les annonces et les plis saisis et sur le profil choisi. Vérifiez les entrées au besoin. Signalez les erreurs et posez vos questions via GitHub Issues.
