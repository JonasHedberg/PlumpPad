Politique de confidentialité

Informations sur les données conservées sur l’appareil, l’export et ce site web.

Responsable et contact

PlumpPad est développé et fourni par Jonas Hedberg. Pour les questions de confidentialité, utilisez GitHub Issues dans le dépôt PlumpPad. Aucune adresse e-mail directe n’est publiée ici. Les issues GitHub sont publiques : ne communiquez pas de données confidentielles.

Données conservées sur l’appareil

L’application peut mémoriser les noms, places, donneurs, annonces, plis, scores, état des parties, dates, résultats et ensembles de règles personnalisées. Les parties actives sont sauvegardées automatiquement; les parties terminées sont conservées selon votre choix d’historique. Ces informations servent au calcul et à la reprise des parties. Aucun compte n’est nécessaire.

Collecte et tiers

La version examinée n’envoie pas de données de partie au développeur ni à son serveur. Elle n’intègre ni publicité, ni analyse tierce, ni suivi. Aucune transmission automatique aux annonceurs. Cette description concerne la version examinée.

Impression, partage et sauvegardes

Les documents PDF et fichiers CSV ne sont créés qu’à votre demande via les fonctions iOS. Le destinataire choisi peut ensuite traiter les données selon ses propres règles. Les sauvegardes iOS ou iCloud peuvent inclure les données locales selon les réglages de l’appareil.

Conservation et effacement

Les parties actives restent disponibles jusqu’à leur fin ou suppression. Les parties terminées sont conservées seulement si l’historique était activé. Les joueurs et règles sauvegardés restent locaux. Supprimez les entrées dans l’app ou désinstallez-la; les sauvegardes et fichiers exportés se gèrent séparément.

Site web et GitHub

Ce site est hébergé par GitHub Pages. Il ne dépose aucun cookie d’analyse propre et ne contient ni publicité ni script de suivi. GitHub peut traiter les données techniques de connexion conformément à sa politique; les issues publiques sont également gérées par GitHub.

Questions et droits

Le développeur ne recevant pas les données des parties, il ne peut normalement ni les consulter ni les supprimer à distance. Gérez-les sur votre appareil. Pour les questions générales, utilisez GitHub Issues sans publier de données personnelles.
