Verantwortlicher und Kontakt

PlumpPad wird von Jonas Hedberg entwickelt und bereitgestellt. Fragen zum Datenschutz können über GitHub Issues im Repository PlumpPad gestellt werden. Auf dieser Website wird keine direkte E-Mail-Adresse veröffentlicht. GitHub Issues sind öffentlich; bitte keine vertraulichen Daten einstellen.

Lokal gespeicherte Informationen

Die App speichert bei Bedarf Namen, Sitzfolge, Geber, Ansagen, gewonnene Stiche, Punkte, Spielstatus, Daten, Ergebnisse und benannte Hausregelsets. Laufende Spiele werden automatisch gespeichert; abgeschlossene Spiele nur nach der Verlaufswahl. Diese Daten werden zur Punkteberechnung und Wiederaufnahme verwendet. Ein Benutzerkonto ist nicht erforderlich.

Übermittlung und Dritte

Die geprüfte Appversion sendet keine Spieldaten an den Entwickler oder dessen Server. Sie enthält weder Werbung noch Analyse-SDKs oder Tracking. Spieldaten werden nicht automatisch an Werbepartner übermittelt. Diese Aussage gilt für die geprüfte Version.

Drucken, Teilen und Sicherungen

PDF-Ausdrucke und CSV-Dateien entstehen erst auf deine Anforderung über iOS-Systemfunktionen. Beim Teilen gelten die Datenschutzregeln des gewählten Empfängers. Lokale Daten können abhängig von den Geräteeinstellungen in iOS-/iCloud-Sicherungen enthalten sein.

Speicherdauer und Löschen

Laufende Partien bleiben bis zum Abschluss oder Löschen erhalten; abgeschlossene Partien bei aktiviertem Verlauf bis zur Löschung. Gespeicherte Spieler und Regeln bleiben lokal. Entferne Spiele oder Verlauf in der App und lösche die App, um lokale Daten zu entfernen; Sicherungen und exportierte Kopien sind gesondert zu verwalten.

Website und GitHub

Diese Website wird über GitHub Pages ausgeliefert. Sie verwendet keine eigenen Analyse-Cookies, Werbeanzeigen oder Tracking-Skripte. GitHub verarbeitet möglicherweise technische Verbindungsdaten nach seiner Datenschutzrichtlinie; öffentliche Issues werden ebenfalls von GitHub verarbeitet.

Fragen und Rechte

Da die Spieldaten nicht beim Entwickler liegen, kann er sie normalerweise nicht aus der Ferne einsehen oder löschen. Verwalte sie direkt auf dem Gerät. Für allgemeine Datenschutzfragen nutze GitHub Issues und veröffentliche dort keine personenbezogenen Spieldaten.
